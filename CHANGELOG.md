# Changelog — obix-component-card

The history of `obix-component-card`. The lineage in full is `PROVENANCE.json`, in this package and in its repository ([https://github.com/obinexus/obix-component-card](https://github.com/obinexus/obix-component-card)).

## 0.5.0

- Named `obix-component-card` without an npm scope (the owner's decision D-102, 2026-09-29). Previous name: `@obinexusltd/obix-component-card`. The package, its version and its exports did not change with the name.
- Repository, issues and homepage: [github.com/obinexus/obix-component-card](https://github.com/obinexus/obix-component-card); the repository starts from a clean export of the OBIX monorepo (its commit is recorded in the repository's copy of PROVENANCE.json).
- A compatibility package: every export is the export of [`obix-core-component`](https://github.com/obinexus/obix-core-component) under the old name (published 0.3.0 (DOP-native)).
